# PhysicsGX

### A 3D Physics Sandbox Game

PhysicsGX is a free 3D physics sandbox game developed using Godot Engine.

The project started as a simple experiment with 3D physics and gradually developed into an interactive playground where players can explore, manipulate objects, and experiment with different physical interactions.

PhysicsGX focuses on giving players a space to experiment with physics without complicated objectives, missions, or restrictions.

You can move around the environment, interact with objects, build structures, knock them down, and observe how different objects react to physical forces.

The game is currently in Alpha development, with new features and improvements being introduced through regular updates.

---

## About PhysicsGX

PhysicsGX is an experimental sandbox game built around physics-based interactions.

Instead of following a traditional gameplay structure, the game allows players to explore an open testing environment filled with different objects and structures.

The main focus is on experimentation.

Players can interact with cubes, spheres, cylinders, dominoes, and other objects that respond to gravity and collisions.

Objects can be moved, pushed, grabbed, dropped, and thrown around the environment.

Different interactions can produce different results depending on the objects involved, their physical properties, and the forces applied to them.

For example, players can build a tower using physics objects and attempt to knock it down by throwing another object at it.

They can also experiment with falling objects, rolling spheres, stacked structures, and chain reactions.

PhysicsGX is designed to be simple to understand while providing opportunities for creative experimentation.

There are no required objectives or missions.

Players are free to explore and interact with the environment however they choose.

## Main Features

### 3D Physics Environment

PhysicsGX features an interactive 3D playground where objects respond to gravity, movement, and collisions.

The game uses Godot's physics engine to simulate rigid body interactions.

Objects react to forces applied by the player and other objects within the environment.

### Interactive Objects

The playground contains different types of physics objects, including:

- Cubes
- Spheres
- Cylinders
- Dominoes
- Stacked structures
- Physics obstacles
- Experimental platforms

Each object can interact with other physical objects in the environment.

### Object Interaction System

Players can interact directly with physics objects.

Available interactions include:

- Picking up objects
- Releasing objects
- Throwing objects
- Pushing objects
- Moving objects around the playground
- Deleting objects
- Spawning new objects

These mechanics allow players to create their own physics experiments.

### First-Person Exploration

PhysicsGX includes a first-person movement system.

Players can walk around the playground, jump, sprint, and control the camera using their mouse.

The first-person perspective allows players to interact directly with objects and structures.

### Physics Experiments

The playground includes different arrangements of objects designed to demonstrate physical interactions.

Players can experiment with:

- Gravity
- Collisions
- Object movement
- Rolling objects
- Falling structures
- Chain reactions
- Object stacking
- Physical forces
- Momentum and impacts

The results of these experiments depend on the behavior of the physics engine.

### Object Spawning

Players can create additional physics objects while playing.

Different keyboard shortcuts allow players to spawn cubes, spheres, cylinders, and dominoes.

This makes it possible to build new arrangements and experiment with larger groups of objects.

### Playground Reset

PhysicsGX includes a reset feature that allows players to restart the playground and repeat experiments.

This is useful when testing different interactions or comparing the results of multiple attempts.

## Audio System

Starting with Alpha 0.2, PhysicsGX includes background music and sound effects.

The audio system was introduced to make the playground feel more responsive and improve the overall gameplay experience.

### Background Music

The game includes ambient background music that plays during gameplay.

The music is intended to provide a relaxed atmosphere while experimenting with physics.

Players can enable or disable background music using the keyboard.

### Sound Effects

Alpha 0.2 introduces several sound effects associated with gameplay interactions.

These include:

- Object collision sounds
- Object grabbing sounds
- Object releasing sounds
- Throwing and pushing sounds
- Player movement sounds
- Jumping sounds
- Object spawning sounds

Some effects use 3D positional audio, allowing their perceived volume to change depending on the distance between the player and the source.

The audio system will continue to be improved in future versions.

## Controls

PhysicsGX supports keyboard and mouse controls on Windows.

### Movement

| Key | Action |
|-----|--------|
| W | Move Forward |
| A | Move Left |
| S | Move Backward |
| D | Move Right |
| Left Shift | Sprint |
| Space | Jump |
| Mouse Movement | Look Around |

### Object Interaction

| Key | Action |
|-----|--------|
| E | Grab or Release Object |
| Right Mouse Button | Grab or Release Object |
| Left Mouse Button | Push Object |
| Left Mouse Button while holding | Throw Object |
| Mouse Wheel Up | Move Held Object Closer |
| Mouse Wheel Down | Move Held Object Farther Away |

### Object Spawning

| Key | Action |
|-----|--------|
| 1 | Spawn Cube |
| 2 | Spawn Sphere |
| 3 | Spawn Cylinder |
| 4 | Spawn Domino |
| B | Spawn Multiple Spheres |

### Environment

| Key | Action |
|-----|--------|
| R | Reset Playground |
| X | Delete Targeted Object |
| H | Show or Hide Controls Panel |
| Escape | Release Mouse Cursor |

### Audio

| Key | Action |
|-----|--------|
| M | Toggle Background Music |
| N | Toggle Sound Effects |

Controls may change between different versions of PhysicsGX.
